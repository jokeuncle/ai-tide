# 潮汐 — native desktop direction

Approved reference: docs/concept.png (static demonstration design, not a live measurement).

Graphite #151719 canvas, off-white #EEEDE9 text, muted text #A7AAA7, jade #9DD8B6 and warm copper #EDAD80. Native macOS window behavior and SF typography; monospaced measurements. Two primary client sculptures, generous space and ruled traffic history. More detail appears in a source inspector, not a dashboard card grid. Artwork is original standalone material, never a crop of the reference UI. Overlay animation amplitude derives only from measured rates; quiet or missing sources have no activity particles. Permission, collection errors, baseline collection, inactive process and no visible socket are distinct states. Support reduced motion and keyboard-accessible native controls. Every live panel must expose its data source and coverage limits.
